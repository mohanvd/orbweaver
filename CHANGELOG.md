# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-12

### Added

- Shape-based module finder that keeps working when Discord renames its exports.
- Runners for video, play, stream and activity quests.
- Reversible store patches that are restored even when a quest fails.
- Test suite that runs every quest type against a fake Discord client.
- Single-file readable bundle at `dist/orbweaver.js`, verified in CI.
